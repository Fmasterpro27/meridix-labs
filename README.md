## About

**Meridix Labs** is an open-source browser testing platform designed to help developers explore and evaluate browser capabilities.

It provides an interactive environment for testing browser APIs, permissions, hardware features, HTML5 components, and more.

Whether you're developing a browser, debugging a web application, or checking browser compatibility, Meridix Labs provides a centralized testing environment.

## Features

### Browser Permissions

- Camera
- Microphone
- Geolocation
- Notifications
- Clipboard
- Bluetooth
- USB
- Serial
- MIDI
- HID

### Device APIs

- Vibration API
- Device Orientation
- Device Motion
- Battery Status
- Screen Orientation
- Wake Lock
- Fullscreen

### HTML Forms

- Text and Password Inputs
- Email and Number Inputs
- Date and Time Inputs
- File Upload
- Color Picker
- Range Slider
- Checkbox and Radio
- Select and Multi-select
- Form Validation
- Custom Validation

### Browser Compatibility

- JavaScript API testing
- Browser feature detection
- Secure Context detection
- HTML5 compatibility
- CSS feature testing

_API availability depends on the browser, operating system, device hardware, and permission settings._

## Getting Started

Meridix Labs is designed to be lightweight and easy to run.

1. Clone the repository.
2. Open the project directory.
3. Serve the files using any static web server.
4. Open the website in your browser.

For APIs requiring a secure context, use HTTPS or localhost.
